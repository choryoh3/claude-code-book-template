# 0005. スタイリングは Tailwind CSS v4 + CSS 変数のデザイントークン

- ステータス: 採用
- 日付: 2026-10-11

## 背景

X の見た目を再現し、ライト/ダークの切り替えにも対応する。管理画面とユーザー画面で見た目の部品を共有したい。

## 検討した選択肢

1. **素の CSS / SCSS** — 自由度は高いが、命名規約の管理や肥大化が課題
2. **UI ライブラリ（Vuetify など）** — 速いが、X 特有の見た目に合わせるのが難しく、見た目の上書きが増える
3. **Tailwind CSS v4 + デザイントークン** — ユーティリティクラスで素早く書ける。v4 は CSS 内で `@theme` によりトークンを定義でき、設定ファイルが不要

## 決定

**選択肢 3** を採用する。

- 色・角丸などは `packages/ui/src/tokens.css` の **CSS 変数**（`--surface`, `--text`, `--accent` など意味のある名前）として一箇所に定義する
- ダークモードは `.dark` クラスでトークンの値を差し替える。各コンポーネントに `dark:` を散らさない
- クラスの合成は `cn()`（clsx + tailwind-merge）、バリアントは `cva()`
- クラス順は `prettier-plugin-tailwindcss` で自動整列する
- アクセシビリティが要る部品（ダイアログなど）は Radix Vue のプリミティブ、アイコンは lucide-vue-next

## 結果

- 良い点: テーマ変更がトークン 1 箇所で済む。見た目の一貫性を保ちやすい
- 注意点: クラスが長くなりがちなので、3 回以上出る組み合わせはコンポーネント化する
