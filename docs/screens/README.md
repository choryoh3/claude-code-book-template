# 画面仕様書

画面ごとの仕様を **Excel**（[画面仕様書.xlsx](./画面仕様書.xlsx)）にまとめています。
基本設計（目的・画面構成・遷移）と詳細設計（項目定義・動作定義・状態表示・テスト観点）の良いところを、画面ごとの 1 枚のシートにまとめた形式です。

## ファイルの構成

```
docs/screens/
├── 画面仕様書.xlsx          # 生成物（Excel）。手で編集しない
├── specs/                   # 元データ（ここを編集する）
│   ├── user-screens.mjs     #   一般ユーザーアプリの画面（U-01〜U-12）
│   ├── admin-screens.mjs    #   管理者アプリの画面（A-01〜A-09）
│   └── common.mjs           #   表紙・画面遷移・共通仕様・メッセージ・用語集
└── captures/                # 実画面のキャプチャ（<名前>.png）
```

## Excel のシート構成

| シート            | 内容                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| 表紙              | 概要、目次（リンク）、改訂履歴、キャプチャの取得状況                 |
| 画面一覧          | 全画面の一覧（ID・URL・認証・目的・項目数・API・テーブル・実装状況） |
| 画面遷移          | 画面から画面への移動                                                 |
| 共通仕様          | レイアウト・入力・通信・アクセシビリティ・セキュリティの共通ルール   |
| メッセージ一覧    | エラー・成功・空状態の文言                                           |
| 用語集            | 用語の説明                                                           |
| U-01 〜 / A-01 〜 | 画面ごとのシート。**基本設計 → キャプチャ → 詳細設計** の順          |

## 更新のしかた

```powershell
# 1. specs/*.mjs を編集（画面・項目・動作を追加・変更）
# 2. Excel を再生成
pnpm spec:screens
```

実画面のキャプチャは、UI を実装したあとに **`/screen-spec`** コマンドで自動取得します（Playwright MCP がブラウザを操作して撮影し、Excel に貼り付けます）。
画像を手で置く場合は、`captures/` に `<名前>.png`（名前は各画面の `captures` に書かれたもの）で保存して `pnpm spec:screens` を実行してください。
