---
description: 関連テストを実行し、失敗したら原因と修正案を示す
argument-hint: [テスト対象のパス]
---

テストを実行してください。対象: $ARGUMENTS（指定がなければ変更ファイルに関連するテスト、それも無ければ全体）

1. `pnpm test`（パス指定があれば `pnpm exec vitest run <path>`）を実行する
2. 失敗があれば、エラーメッセージとスタックトレースから **根本原因** を特定する
3. テストの期待値が古いのか、実装のバグなのかを区別して報告する
4. 修正案を提示し、ユーザーの了承を得てから直す（テストを通すためだけに期待値を変えない）
5. 修正後に再実行し、結果（成功/失敗の件数）を報告する
