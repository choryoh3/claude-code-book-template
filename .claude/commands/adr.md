---
description: docs/adr/ に ADR（設計判断の記録）をテンプレートから作成する
argument-hint: <ADR のタイトル>
---

ADR「$ARGUMENTS」を作成してください。

1. `docs/adr/` の既存ファイルを調べ、次の連番（`0006-...` のような 4 桁）を決める
2. ファイル名は `NNNN-kebab-case-title.md`
3. 次のテンプレートで書く。**背景・選択肢・理由** を初心者にも伝わる言葉で説明する

   ```markdown
   # NNNN. タイトル

   - ステータス: 提案 / 採用 / 廃止（置き換え先: NNNN）
   - 日付: YYYY-MM-DD

   ## 背景

   何が問題で、なぜ決める必要があったか。

   ## 検討した選択肢

   1. 選択肢 A — 長所 / 短所
   2. 選択肢 B — 長所 / 短所

   ## 決定

   採用する案と、その理由。

   ## 結果

   この決定によって得られること、受け入れるデメリット、今後の注意点。
   ```

4. ユーザーに内容を確認してもらう。他の ADR を置き換える場合は旧 ADR のステータスも更新する
