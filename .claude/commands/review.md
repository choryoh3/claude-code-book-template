---
description: 現在の差分を code-reviewer サブエージェントでレビューする
---

`code-reviewer` エージェントを起動し、現在の変更（`git diff` と未追跡ファイル）をレビューさせてください。

レビュー観点:

- セキュリティ（認証・認可、入力検証、秘密情報の漏洩、XSS / SQL インジェクション）
- N+1 クエリ・インデックス不足・トランザクション漏れ
- 型安全性（`any`、不適切な型アサーション）
- admin / user の境界違反、admin 操作の監査ログ漏れ
- 可読性（命名・関数の責務・コメントの質）と、テスト・seed の更新漏れ

結果は「重大 / 改善推奨 / 提案」に分けて、ファイルと行番号つきで報告してください。
指摘を修正するかどうかはユーザーに確認してください（勝手に修正しない）。
