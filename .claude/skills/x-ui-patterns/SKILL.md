# X の UI パターン

数値は目安。実装は `packages/ui` のデザイントークンを通して行い、固定値を直書きしない。

## レイアウト（デスクトップ）

| 領域         | 幅                                             | 内容                                                                             |
| ------------ | ---------------------------------------------- | -------------------------------------------------------------------------------- |
| 左サイドナビ | 約 275px（~1280px 未満はアイコンのみ 約 88px） | ロゴ、ホーム/検索/通知/ブックマーク/プロフィール、投稿ボタン、アカウントメニュー |
| 中央         | 最大 600px（左右に 1px の境界線）              | タイムライン。上部は sticky ヘッダー（タブ）                                     |
| 右サイドバー | 約 350px（~1000px 未満は非表示）               | 検索ボックス、トレンド、おすすめユーザー                                         |

モバイルは下部タブバー + 右下の浮遊投稿ボタン。

## 配色トークン（意味ベース）

| トークン              | ライト                            | ダーク                         |
| --------------------- | --------------------------------- | ------------------------------ |
| `surface`             | 白                                | 黒（#000）または非常に濃い青灰 |
| `text` / `text-muted` | 黒 / 灰（#536471）                | 白 / 灰（#71767b）             |
| `border`              | 薄灰                              | 濃灰                           |
| `accent`              | 青（#1d9bf0）                     | 同左                           |
| `like` / `repost`     | ピンク（#f91880） / 緑（#00ba7c） | 同左                           |

## 投稿カード

```
[Avatar 40px] [表示名] [@handle] · [相対時刻]            [⋯]
              本文（改行・ハッシュタグ・メンション・URL をリンク化）
              メディア（1〜4 枚のグリッド、角丸 16px）
              [返信数] [リポスト数] [いいね数] [ブックマーク] [共有]
```

- ホバーで背景がわずかに変わる。カード全体クリックで詳細へ、内部のボタン/リンクは伝播を止める
- アクションは色付きホバー（返信=青、リポスト=緑、いいね=ピンク）。押下状態でアイコンが塗りつぶされ、数値が更新される（楽観的更新）
- リポストは上部に「○○さんがリポストしました」、引用は本文の下に枠付きで元投稿を埋め込む

## インタラクション

- 無限スクロール: 末尾の sentinel を IntersectionObserver で監視し、cursor で次ページ取得
- 新着投稿は上部に「N 件の投稿を表示」ピルを出し、押したときだけ挿入する（勝手にスクロールを動かさない）
- 280 文字カウンタは円形リング。残り 20 文字で色が変わり、超過で赤と投稿ボタン無効
- 投稿・削除・フォローの結果は短時間のトーストで通知する
