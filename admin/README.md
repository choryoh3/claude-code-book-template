# admin/ — 管理者アプリ

運営者が使う **管理画面と管理 API** です。一般ユーザーのアプリとは物理的に分けています。

| フォルダ  | 役割                                                                       | ポート |
| --------- | -------------------------------------------------------------------------- | ------ |
| `client/` | 管理画面（Vue 3 + Vite）。ダッシュボード・ユーザー/投稿/通報管理・監査ログ | 5174   |
| `server/` | 管理 API（Express 5）。管理者認証・RBAC・各種管理操作                      | 3001   |

- 実装は Phase 5（server）と Phase 6（client）。現在は空です（`docs/roadmap.md`）
- 管理者は **別の認証エンドポイント・別の JWT シークレット** を使います（`docs/adr/0004-jwt-auth-strategy.md`）
- **管理者の変更操作は必ず監査ログに記録** します（`.claude/rules/admin-security.md`）
- 一般ユーザーのアプリ（`../user/`）の API を呼ばないでください
